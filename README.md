The simplest PyTorch Lightning binary classifier model with training, inference, and export to ExecuTorch format.

Quick command to copy a file to a Raspberry Pi zero 2W over SCP (replace ip_address with your Pi's IP):
scp /path/to/local_file <username>@<pi-ip>:/home/<username>/coding-projects/<project_name>/
    - no need to specify the destination file name, it will be the same as the source file name.
